# Nuestra propuesta

Buscamos desarrollar un sistema informático que nos permita interactuar en lenguaje natural,
obteniendo respuestas a preguntas planteadas a un LLM (modelo de lenguaje de gran tamaño) 
ejecutado en forma local (LLAMA7B).

Estos modelos logran generar contenido de forma correcta, gracias a su extenso entrenamiento con grandes cantidades de datos, pero carecen de conocimiento que les permitan contestar con verdad a los preguntas planteadas. Por lo tanto, pensamos desarrollar una base de datos de noticias regionales, nacionales e internacionales que nos permita implementar algoritmo de generación asistida por búsqueda de datos (Retrieval Assisted Generation).

Cabe notar que existen diversas implementaciones de código abierto que podemos emplear como punto de partida para el sistema buscado.
